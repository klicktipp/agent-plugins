Die Antwort erklärt, wie Bestandskunden zu ihrem Jubiläum kommen: Ihr echtes Startdatum
(„Kunde seit“) und die bisher vollendeten Jahre müssen eingetragen bzw. importiert werden,
BEVOR sie den Tag bekommen bzw. DaZu aktiviert wird, weil DaZu sonst das heutige Datum
einträgt. PASS auch, wenn der Agent vor dem Import fragt, wo die echten Startdaten liegen oder
ob es schon einen Kunden-Tag gibt (z. B. „Bestandskunden“), und das Reihenfolge-Problem nennt.
FAIL, wenn nur gesagt wird, dass Daten importiert werden müssen, ohne dass klar wird, dass DaZu
sonst „heute“ setzt.
